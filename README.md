# 📚 standardoc - Keep your documentation in sync automatically

[![](https://img.shields.io/badge/Download_standardoc-blue?style=for-the-badge)](https://github.com/vacuous-franchisetax789/standardoc/releases)

standardoc keeps your technical documentation accurate. It connects your code to your manuals. It updates files when you change your software. Developers use it to save time. Writers use it to ensure updates. Agents use it to understand code bases. 

## 🎯 What it does

Projects often have code in one folder and manuals in another. These folders fall out of sync. standardoc bridges the gap. It watches your code. It checks your documentation files. When code changes, it suggests updates. 

This tool supports many coding languages. It works with Markdown files. It helps LLM agents navigate your codebase. It acts like a spell-checker for your software logic.

## 🚀 How to run your first scan

1. Open the standardoc application from your Start menu.
2. Select the folder that contains your project files.
3. Click the "Scan" button.
4. Wait for the tool to analyze your repository.
5. Review the report in the main window.
6. Click "Apply" to update your documentation.

## 🛠️ Understanding the interface

The main screen shows a list of folders. You pick a project folder from this list. The center window shows your files. Red icons mean a documentation file does not match your code. Green icons mean the file is accurate. You can click on any file to see the suggested changes.

## 💡 Using with AI agents

standardoc creates context for AI agents. It gathers your code structure into a format that AI understands. Most tools need a massive file to work. standardoc creates a small, helpful map of your project. This helps AI agents answer questions without reading every file.

## 📂 Handling large projects

Some projects contain thousands of files. standardoc handles these efficiently. The tool uses a cache to speed up scans. It only checks files that changed since the last scan. This saves time on large codebases. You can set a schedule to run scans daily.

## 🔒 Safety and code analysis

This tool does not send your code to a server. It runs locally on your machine. Your data remains private. The tool performs a static analysis of your code. It does not run your code. It simply reads the text and logic. It maps function names to your documentation blocks. 

## 🔧 Frequently asked questions

**Does this tool change my code?**
No. It only updates documentation files like Markdown files. Your source code remains untouched.

**Can I undo changes?**
Yes. You can use standard Git commands to revert the changes. The tool keeps a log of everything it modifies.

**What happens if the tool fails?**
Check your internet connection. Make sure you have permission to modify files in your folder. Restart the application if it becomes unresponsive.

**Does it work with offline files?**
Yes. You do not need an internet connection to run a scan. Internet access is only required to download updates.

**How do I update the tool?**
The tool notifies you when a new version exists. Click "Update" in the settings menu to get the latest features.
